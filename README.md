# АИС «Автомат выдачи билетов на электричку»

Учебное веб-приложение на Python + Flask + SQLite. Интерфейс пассажира и интерфейс администратора разделены.

## Возможности

### Пассажир
- выбор направления, станции отправления/прибытия, даты и времени;
- дата поездки ограничена диапазоном от сегодня до 10 суток вперёд;
- внесение номиналов 1, 2, 5, 10 и 20 рублей;
- проверка достаточности суммы и наличия сдачи;
- возврат внесённых денег до завершения покупки;
- формирование электронного макета билета.

### Администратор
- вход в отдельную панель;
- просмотр продаж и выручки за текущую дату;
- просмотр состава денежного ящика;
- добавление и изъятие купюр/монет;
- изменение остатка бумаги;
- смена пароля;
- выгрузка отчёта CSV.

## Запуск на Windows

1. Установите Python 3.10 или новее с сайта https://www.python.org/downloads/.
2. Распакуйте архив в отдельную папку.
3. Дважды нажмите `run.bat`.
4. При первом запуске скрипт создаст виртуальное окружение, установит Flask и запустит сервер.
5. Откройте в браузере адрес: http://127.0.0.1:5000

Остановка сервера: `Ctrl + C` в окне консоли.

## Вход администратора

- Адрес: http://127.0.0.1:5000/admin/login
- Начальный пароль: `admin20`

После входа пароль можно поменять в разделе «Безопасность».

## Ручной запуск (Windows / macOS / Linux)

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

Затем откройте http://127.0.0.1:5000

## База данных

SQLite-файл `kiosk.db` создаётся автоматически при первом запуске. В нём хранятся:
- `tickets` — проданные билеты;
- `cash_inventory` — остатки номиналов в денежном ящике;
- `settings` — настройки, остаток бумаги и пароль администратора;
- `transactions` — записи о продажах.

Не удаляйте `kiosk.db`, если хотите сохранить данные. Чтобы начать заново, остановите сервер и удалите этот файл — он будет создан повторно с начальными значениями.

## Примечание

Это учебный прототип, а не готовая платёжная система. Приём денег, принтер и передача данных транспортной компании имитируются программно. Для реального использования потребуются защищённая авторизация, серверная интеграция, аппаратные драйверы и дополнительная проверка безопасности.
